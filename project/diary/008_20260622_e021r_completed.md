## Bug caught and fixed

Initial run incorrectly flagged 2-trace motifs (canonical, strong_overlap) as
`universal_linking=YES` because they have no unlinked pairs by definition (only one pair exists).
Fix: `universal_linking_flag` is only set for n_traces > 2 with no unlinked pairs.
2-trace motifs with a single expected-linked pair are not "universal linking" cases.

## Key findings

### 1. Hub overlap is NOT a clean generalization success

hub_overlap passes gSIG-A/B/D/E (mechanistic_pass=True) but fails specificity
because all trace pairs are universally linked through the hub branch.
This is now formally classified as `hub_overlinking_boundary`.
The article language states this explicitly.

### 2. Two-trace motifs: specificity not applicable (N/A, not failure)

canonical and strong_overlap have no unlinked pairs by definition (only one pair exists
for 2-trace motifs). The absence of a false-linking metric is not a deficiency —
it is structurally impossible to measure specificity with only one trace pair.
These are correctly NOT flagged as `universal_linking`.

### 3. Chain overlap: partial specificity (FL ≈ 0.19, "good" band)

Chain topology passes specificity: local pairs gain ~5× more linking than distant pairs.
Classified as `chain_local_linking_with_leakage` — mechanistic success with documented leakage.

### 4. Sparse random: seed-dependent specificity

Some seeds produce all-linked configurations at larger branch counts (density effect):
when n_branches × density is high enough, all 4-trace pairs share at least one active branch,
making false-linking undefined. This is a valid density/scale boundary finding.
Seeds producing sparse enough allocations (s123 at n=8,16) pass specificity (FL=0.16–0.30).

### 5. Predeclared FL thresholds

```
good:      FL < 0.25
moderate:  FL < 0.50
poor:      FL < 1.00
very_poor: FL ≥ 1.00
```

Chain (FL ≈ 0.19) falls in "good." Sparse s123 n=16 (FL = 0.303) falls in "moderate."

## Article-facing language (excerpt)

> The mechanism generalized beyond the canonical four-branch/two-trace case in motifs
> with sufficient but not universal overlap. Strong-overlap, chain, and sparse-random
> motifs preserved the expected slow-writing and linking signatures, while weak-overlap
> motifs failed as predicted by the overlap-threshold boundary. Hub-overlap motifs
> produced strong structural writing and linking but lacked specificity because all
> traces shared the same hub branch. We therefore treat hub overlap as an over-linking
> boundary condition rather than as a clean success case.
