## Core finding: why E019 SIG-E differed from E017/E018

| Experiment | SIG-E | Protocol variant |
|---|---|---|
| E017 | +0.333 NR | Post-cons + post-damage probe cues before rescue |
| E018 | +0.333 NR | Same as E017 (identical) |
| E019 | +1.547 NR | No inter-phase probe cues |
| E019R | +1.547 NR | No inter-phase probe cues (confirms E019) |

**Root cause:** In E017/E018, probe cues (MU1_CUE, MU2_CUE) are applied between
consolidation and damage, and again between damage and rescue. These probes rebuild E_b
on b0, b1, b2 *before* the rescue comparison begins. This "warms up" the generic plain
consolidation baseline — generic rescue can actually write M_b because E_b is pre-loaded.

In E019/E019R, there are no inter-phase probes. After 9 null damage passes, E_b is
depleted. Generic plain consolidation has essentially zero E_b to drive any M_b write.
The result: **generic rescue actively FURTHER DECREASES L** (NR = −0.553), because b1's
elevated decay rate continues during the 9 consolidation passes with no write occurring.

Targeted rescue (B1_CUE × 3 reps per round) specifically rebuilds E_b on b1 before each
consolidation window, counteracting the ongoing decay. Result: NR_targeted = +0.995.

**SIG_E_normalized = 0.995 − (−0.553) = +1.547**

This is a stronger and more mechanistically clean finding than E017/E018's +0.333:
- It directly demonstrates that **non-targeted consolidation cannot reverse ongoing
  structural damage** (generic NR < 0)
- Only **branch-specific re-excitation** can rescue the overlap branch

## SIG-E audit: 5 rescue conditions

| Rescue condition | NR | Absolute rec | Overshoot |
|---|---|---|---|
| no_rescue | 0.000 | 0.0000 | No |
| targeted_overlap_rescue | +0.995 | +0.1406 | No |
| generic_plain_consolidation | −0.553 | −0.0781 | No |
| generic_all_branch_precue | +1.137 | +0.1608 | **Yes** |
| nonoverlap_branch_rescue | −0.516 | −0.0729 | No |

Key insight: `generic_all_branch_precue` (GENERIC_CUE × 3 reps + consolidate × 3 × 3 rounds)
gives HIGHER recovery (NR = +1.137) than targeted (NR = +0.995). This means SIG-E would be
**negative** if we used all-branch precue as the reference — confirming that `generic_plain_consolidation`
(no pre-cue) is the correct reference baseline for the discrimination claim.

`nonoverlap_branch_rescue` (cue b0+b2 only) gives NR = −0.516 (similar to plain consolidation,
because b0 and b2 cueing does not help b1 recover). This further confirms the branch-specificity
of the rescue effect.
