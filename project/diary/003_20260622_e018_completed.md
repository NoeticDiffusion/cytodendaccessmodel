## Notable findings

### SIG-C pattern
All comparators pass SIG-C. Context separation (SIG-C ≈ +0.15) appears to emerge from the
contextual allocation structure itself, independent of whether M_b is updated. This is
consistent: the fast context gating (`context_gain`, `ALPHA_BIAS` / `BETA_BIAS`) is active
in all comparators including `fast_context_only`. SIG-C alone therefore does not discriminate
the models. This is scientifically meaningful — it suggests context gating is a structural property
of the allocation, not an emergent property of slow plasticity.

### SIG-D pattern (linking > recall dissociation)
Three comparators (`fast_context_only`, `replay_no_structure`, `fixed_allocation_only`) also
pass SIG-D (+19 pp). This is because the damage still selectively impairs the overlap branch
even when M_b cannot be written, causing linking to drop proportionally more than recall
(recall is driven by overall branch activity, not M_b alone). SIG-D alone is therefore
also not discriminative, but the combination with SIG-A and SIG-B is.

### SIG-E methodological refinement
The first run used `GENERIC_CUE` (all branches driven at 0.5) as the generic rescue baseline.
This made targeted rescue look worse (SIG-E = −7.4 pp) because generic rescue also drove b1.
The correct baseline — matching exp015 — is **plain consolidation without any pre-cueing**
(same total passes, no E_b pre-loading). With this fix, SIG-E = +33.3 pp for full_model.

The SIG-E definition and this methodological decision are fully documented in
`results/e018_comparator_trace_matrix/summary/rescue_protocol.md`.

### SIG-C trace export
SIG-C is computed in a separate context-probe simulation and exported to
`traces/<comparator>_context_probe_traces.csv`. The main branch traces do not include
`context_value` per step. This limitation is documented in
`summary/context_probe_limitations.md`. Full time-resolved context trace integration is
deferred to E019.

## Limitations

1. **Only canonical parameters.** The discrimination result holds under exp013 BASE_PARAMS.
   Parameter robustness requires E019.
2. **Five comparators only.** Optional comparators (`hebbian_weight_only`, `soma_global_gain_only`,
   `shuffled_replay`, `eligibility_only`, `resource_only`) not implemented.
   See `results/e018_comparator_trace_matrix/future_comparators.md`.
3. **SIG-C not time-resolved.** Context separation is computed post-consolidation only.
4. **Four-branch canonical motif only.** No scaling or noise robustness.
5. **SIG-E baseline choice matters.** Documented in rescue_protocol.md.
