# E021R — Generalized Specificity Gate and Hub-Failure Audit

## Purpose

Refine the generalized motif-signature protocol after E021.

E021 showed that the slow-writing mechanism generalizes across several motifs and branch counts, but it also revealed an important boundary condition:

```text
hub_overlap passes gSIG-A/B/D/E,
but all trace pairs are universally linked.
There are no unlinked pairs, so false-linking specificity is undefined.
```

This means that “joint pass” alone is not sufficient for multi-trace motif interpretation.

E021R should add a specificity-aware interpretation layer before proceeding to harder comparators.

---

## Core research question

Can generalized motif success be separated into:

```text
mechanistic success:
    expected overlap branches write,
    expected linked pairs gain linking,
    perturbation/rescue behaves as predicted

specificity success:
    expected linked pairs gain more than unlinked or distant pairs,
    false-linking remains bounded,
    hub-like motifs are correctly classified as over-linking boundary conditions
```

### 2. Define specificity metrics

Use at least two metrics where applicable.

#### False-linking rate

```text
false_linking_rate =
    mean(delta_L_unlinked_pairs) /
    mean(delta_L_expected_linked_pairs)
```

Interpretation:

```text
0.00–0.25: good specificity
0.25–0.50: moderate leakage
0.50–1.00: poor specificity
undefined: no unlinked pairs exist
```

Thresholds can be adjusted, but must be predeclared.

#### Specificity index

```text
specificity_index =
    mean(delta_L_expected_linked_pairs) - mean(delta_L_unlinked_pairs)
```

Use this as a raw difference metric.

#### Universal-linking flag

```text
universal_linking_flag = no unlinked trace pairs exist
```

This should trigger a warning, not a silent pass.

```text
The mechanism generalized beyond the canonical four-branch/two-trace case in motifs with sufficient but not universal overlap. Strong-overlap, chain, and sparse-random motifs preserved the expected slow-writing and linking signatures, while weak-overlap motifs failed as predicted by the overlap-threshold boundary. Hub-overlap motifs produced strong structural writing and linking but lacked specificity because all traces shared the same hub branch. ```
```

## Acceptance criteria

E021R is complete when:

1. Hub motifs are explicitly classified as over-linking boundary conditions.
2. Weak-overlap motifs are explicitly classified as expected failures.
3. Chain and sparse motifs receive specificity metrics.
4. The article-facing language distinguishes mechanistic generalization from specificity-preserving generalization.
5. Tests pass.
6. Claim ledger is updated.

## Claim discipline

Allowed after E021R:

```text
The slow-writing mechanism generalizes to selected non-canonical motifs.
The mechanism requires sufficient overlap.
Hub-like overlap produces strong linking but poor specificity.
Chain and sparse motifs preserve partial specificity under tested conditions.
The generalized result is bounded by overlap topology.
```

Not allowed:

```text
All motif classes are clean successes.
Hub overlap proves generalization.
The model generalizes to arbitrary memory systems.
The model scales to realistic dendritic trees.
```
