# E019 — One-at-a-Time Parameter Robustness

## Purpose

Test whether the full model’s joint SIG-A to SIG-E profile survives one-at-a-time variation of key simulator parameters.

E017 established reproducible canonical traces.
E018 established that, under canonical parameters, no simpler tested comparator reproduces the full SIG-A to SIG-E profile.

E019 asks the next reviewer-facing question:

```text
Is the full model’s joint signature profile robust to parameter variation,
or is it a narrow artifact of the canonical parameter set?
```

This experiment should not introduce new biology, new DANDI analyses, or new scaling motifs. It is a controlled robustness audit of the canonical full model.

---

## Core research question

For each key parameter, how wide is the range over which the full model preserves:

```text
SIG-A  overlap-branch structural writing
SIG-B  linking gain after consolidation
SIG-C  context separation
SIG-D  linking > recall dissociation under overlap damage
SIG-E  targeted rescue selectivity
```

and how does each signature fail when the parameter leaves the functional regime?

## Suggested sweep values

Use repository constants as source of truth for canonical values. The values below are suggested starting ranges, not a substitute for inspecting actual `BASE_PARAMS`.

### structural_lr

```text
[0.00, 0.03, 0.06, 0.09, 0.12, 0.15, canonical, 0.21, 0.27, 0.33, 0.40]
```

Expected boundary: SIG-A and SIG-B should fail near zero.

### replay_gain

```text
[0.00, 0.10, 0.25, 0.40, 0.60, canonical, 1.00, 1.25, 1.50]
```

Expected boundary: no replay gain should reduce slow writing and linking gain.

### eligibility_decay

```text
[0.02, 0.05, 0.08, canonical, 0.16, 0.24, 0.32, 0.45, 0.60]
```

Expected boundary: very fast eligibility decay should impair delayed consolidation.

### structural_decay

```text
[0.00, canonical, 0.01, 0.02, 0.035, 0.05, 0.08]
```

Expected boundary: high decay should degrade persistence of `M_b` and linking.

### structural_noise

```text
[0.00, 0.005, 0.01, 0.02, 0.035, 0.05, 0.08]
```

For nonzero noise, run multiple seeds.

Suggested seeds:

```text
[0, 1, 2, 3, 4, 42, 101, 202, 303, 404]
```

Expected boundary: moderate noise should preserve direction; high noise may break specificity.

### context_gain

```text
[0.00, 0.25, 0.50, canonical, 1.50, 2.00, 3.00]
```

Expected boundary: SIG-C should depend strongly on context gain. If SIG-A/B remain stable while SIG-C varies, that supports mechanistic separation between fast context gating and slow structural writing.

### timing_gap

Define as the delay between encoding and consolidation, or as the number of neutral/no-write decay steps before consolidation.

Suggested values:

```text
[0, 1, 2, 4, 8, 12, 16, 24]
```

Expected boundary: long timing gaps should impair eligibility-dependent writing.

### overlap_strength

Vary shared branch allocation strength for b1.

Suggested values:

```text
[0.00, 0.10, 0.25, 0.40, 0.60, canonical, 0.90, 1.00]
```

Expected boundary: weak overlap should reduce linking and targeted rescue advantage.

### readout_threshold

```text
[0.10, 0.20, 0.30, canonical, 0.60, 0.75, 0.90]
```

Expected boundary: very high thresholds may collapse recall support; very low thresholds may reduce separation.

## Key interpretive rules

### Allowed claims if successful

```text
The full model’s canonical joint signature profile is not a single-run artifact.
The joint profile survives one-at-a-time variation across defined parameter ranges.
Some signatures have identifiable failure boundaries.
Context separation and slow-writing signatures show separable parameter dependencies.
```

### Allowed if failures occur

```text
The model is robust only within a bounded parameter regime.
The sweep identifies biologically meaningful failure boundaries.
The result constrains the model rather than invalidating it.
```

### Not allowed after E019

```text
The model is robust to all parameter combinations.
The model scales beyond the four-branch motif.
The model survives pairwise parameter interactions.
The model is biologically validated.
The model is supported by DANDI.
```

Those require later experiments.

## Special attention points

### SIG-C

E018 showed that SIG-C is passed by all comparators and is not diagnostic of slow structural writing.

In E019, use `context_gain` to test whether SIG-C is mainly a fast-context / allocation signature.

If confirmed, the article should state:

```text
Context separation is an architectural fast-gating signature,
not a diagnostic marker of slow structural writing.
```

This is a useful result, not a weakness.

### SIG-D

E018 showed that several comparators pass SIG-D. Therefore, SIG-D should not be treated as diagnostic alone.

In E019, test whether SIG-D is stable or inflated by the damage protocol.

If SIG-D remains broad across many parameter values, article interpretation should be:

```text
Linking-vs-recall dissociation follows partly from overlap-branch geometry and perturbation targeting.
It becomes diagnostic only when combined with SIG-A, SIG-B, and SIG-E.
```

### SIG-E

E018 showed that SIG-E depends on rescue baseline definition.

In E019, preserve the E018 rescue protocol exactly.

Do not change generic rescue during E019. If rescue sensitivity needs deeper study, make it a later dedicated experiment.
