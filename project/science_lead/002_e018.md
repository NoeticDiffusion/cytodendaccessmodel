# E018 — Comparator Trace Matrix

## Purpose

Run the new E017 trace-export machinery across comparator baselines to determine whether the full branch-accessibility model uniquely reproduces the joint signature profile SIG-A to SIG-E.

E017 established that the canonical full model emits reproducible traces and passes all five protected signatures under canonical parameters. E018 asks the next reviewer-facing question:

```text
Do simpler comparator models reproduce the same joint profile,
or does the profile require replay-dependent slow structural writing?
```

This is the first real model-discrimination experiment for article v2.

---

## Core research question

Which components are necessary for the canonical joint signature profile?

Specifically, can any simpler baseline reproduce the combination of:

```text
SIG-A  overlap-branch structural writing
SIG-B  linking gain after consolidation
SIG-C  context separation
SIG-D  linking > recall dissociation under overlap damage
SIG-E  targeted rescue selectivity
```

or is the full model required?

## Required comparators

Run the E017-style trace export and SIG-A to SIG-E computation for at least these five models:

```text
full_model
fast_context_only
replay_no_structure
random_slow_drift
fixed_allocation_only
```

Definitions should be explicitly exported into metadata.

### Comparator definitions

#### full_model

Fast access, eligibility, replay/capture support, and replay-dependent slow structural writing are all active.

Expected result: should pass the joint SIG-A to SIG-E profile.

#### fast_context_only

Fast contextual gating exists, but slow structural state does not update.

Expected failure: may preserve SIG-C, but should fail slow-writing-dependent signatures such as SIG-A, SIG-B, SIG-D, or SIG-E.

#### replay_no_structure

Replay exists and may affect transient activity/resources, but cannot write persistent `M_b`.

Expected failure: replay alone should not produce durable overlap-branch structural writing.

#### random_slow_drift

A slow variable changes with matched or comparable magnitude, but without branch-specific eligibility/replay dependence.

Expected failure: may produce nonspecific structural change, but should fail selective overlap writing and targeted rescue specificity.

#### fixed_allocation_only

Trace overlap exists by construction, but dynamic structural updating is removed.

Expected failure: may produce baseline overlap-linked support, but should not show replay-dependent linking growth or structural writing.

### Acceptable fallback

```text

```

Do not silently merge incomparable traces.

## Required methodological fix for SIG-E

E017 reported that SIG-E has no generic rescue comparator.

For E018, define rescue conditions explicitly.

Minimum acceptable rescue conditions:

```text
targeted_overlap_rescue
generic_all_branch_rescue
nonoverlap_branch_rescue
no_rescue
```

If implementation time is limited, at least compare:

```text
targeted_overlap_rescue
generic_all_branch_rescue
```

SIG-E should be calculated as:

```text
SIG_E = L_targeted_overlap_rescue - L_generic_or_non_targeted_rescue
```

Document the exact rescue protocol in:

```text
summary/rescue_protocol.md
```

Do not interpret SIG-E strongly if generic rescue is absent.

## Signature thresholds

Use the same directional logic as E017 first.

Then add a second stricter pass/fail layer:

```text
directional_pass: score > 0
protected_pass: score exceeds predeclared threshold
```

Suggested initial protected thresholds:

```text
SIG-A: overlap advantage > 0.02 delta M_b
SIG-B: linking gain > 0.05 delta L
SIG-C: context separation > 0.05 support
SIG-D: linking-vs-recall dissociation > 5 percentage points
SIG-E: targeted rescue advantage > 10 percentage points
```

If these thresholds differ from exp015, preserve exp015 values and document the exact values used.

The important point is that thresholds must be predeclared in the output metadata, not chosen after seeing results.

## Acceptance criteria

E018 is complete when:

1. All required comparators run.
2. Each comparator exports branch, support, and linking traces.
3. SIG-A to SIG-E are computed for each comparator.
4. A comparator signature matrix is produced.
5. The full model passes the joint profile.
6. At least one simpler comparator fails the joint profile.
7. Ideally, no simpler comparator passes all five protected signatures.
8. SIG-C limitations from E017 are either fixed or explicitly documented.
9. SIG-E has a defined rescue comparator or is explicitly downgraded.
10. All tests pass.

## Claim discipline

### Claims allowed if E018 succeeds

```text
The simulator can now compare the full model against simpler baselines using the same trace-export and signature machinery.
The full model reproduces the canonical joint signature profile.
One or more simpler baselines fail to reproduce the joint signature profile.
The model-discrimination claim is now internally testable.
```

### Claims allowed only if no simpler comparator passes all five signatures

```text
Under canonical parameters, the joint SIG-A to SIG-E profile is specific to the full replay-dependent slow structural writing model among the tested comparators.
```

### Claims not allowed after E018

```text
The model is robust across parameter ranges.
The biological mechanism is validated.
The cytoskeletal hypothesis is proven.
The result generalizes beyond the canonical four-branch setup.
The result survives scaling, noise, or motif variation.
DANDI data validate the model.
```

Those require later experiments.
