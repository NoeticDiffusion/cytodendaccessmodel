# E020 — Two-Parameter Robustness Heatmaps

## Purpose

Test whether the full model’s joint SIG-A to SIG-E profile survives biologically meaningful two-parameter interactions.

E017 established trace export.
E018 established comparator discrimination under canonical parameters.
E019 established one-at-a-time robustness.
E019R locked signature definitions and resolved the SIG-E protocol discrepancy.

E020 now asks:

```text
Does the full model remain functional across two-dimensional parameter regions,
or do interactions between key parameters reveal hidden fragility?
```

This is the next major reviewer-facing robustness experiment.

---

## Core research question

For each biologically meaningful parameter pair, where does the full model preserve the joint signature profile?

Protected signatures:

```text
SIG-A  overlap-branch structural writing
SIG-B  linking gain after consolidation
SIG-C  context/allocation separation
SIG-D  linking > recall dissociation under overlap damage
SIG-E  targeted rescue selectivity, using locked E019R normalized-recovery definition
```

The primary endpoint is:

```text
joint_protected_pass = SIG-A & SIG-B & SIG-C & SIG-D & SIG-E
```

Secondary endpoints:

```text
per-signature protected pass
raw signature values
failure mode
first failed signature
```

## Suggested grids

Use E019 failure boundaries to choose grids that cover both robust and failing regimes.

### structural_lr × replay_gain

```text
structural_lr: [0.00, 0.03, 0.06, 0.09, 0.12, 0.15, canonical, 0.21, 0.27, 0.33, 0.40]
replay_gain:   [0.00, 0.10, 0.25, 0.40, 0.60, canonical, 1.00, 1.25, 1.50]
```

Expected: low-low corner should fail SIG-A/B/E. Robust region should emerge when both write capacity and replay support are sufficient.

### eligibility_decay × timing_gap

```text
eligibility_decay: [0.02, 0.05, 0.08, canonical, 0.16, 0.24, 0.32, 0.45, 0.60]
timing_gap:        [0, 1, 2, 4, 8, 12, 16, 24]
```

Expected: long timing gaps combined with fast eligibility decay should fail slow writing and linking.

### structural_decay × structural_lr

```text
structural_decay: [0.00, canonical, 0.01, 0.02, 0.035, 0.05, 0.08]
structural_lr:    [0.00, 0.03, 0.06, 0.09, 0.12, 0.15, canonical, 0.21, 0.27, 0.33, 0.40]
```

Expected: higher structural decay may be compensated by higher structural learning rate up to a point.

### structural_noise × replay_gain

```text
structural_noise: [0.00, 0.005, 0.01, 0.02, 0.035, 0.05, 0.08]
replay_gain:      [0.00, 0.10, 0.25, 0.40, 0.60, canonical, 1.00, 1.25, 1.50]
```

Use multiple seeds for nonzero noise.

Suggested seeds:

```text
[0, 1, 2, 3, 4, 42, 101, 202, 303, 404]
```

Endpoint should include:

```text
joint_pass_fraction_across_seeds
mean signature score
signature score spread
```

### overlap_strength × replay_gain

```text
overlap_strength: [0.00, 0.10, 0.25, 0.40, 0.60, canonical, 0.90, 1.00]
replay_gain:      [0.00, 0.10, 0.25, 0.40, 0.60, canonical, 1.00, 1.25, 1.50]
```

Expected: weak overlap should fail linking-related signatures even with replay. Strong overlap with sufficient replay should pass.

### context_gain × structural_lr

```text
context_gain:  [0.00, 0.25, 0.50, canonical, 1.50, 2.00, 3.00]
structural_lr: [0.00, 0.03, 0.06, 0.09, 0.12, 0.15, canonical, 0.21, 0.27, 0.33, 0.40]
```

Expected: SIG-C may remain robust due to allocation geometry, while SIG-A/B/E depend on structural_lr. This pair should help separate fast-context/allocation signatures from slow-writing signatures.

DANDI data validate the model.
